# Controlled physical shift feasibility — assessment only

No dynamics-shift method is selected or implemented. This assessment follows source inventory, not physical campaign results. Downstream RL remains in Fluidgym-RL. Matching that repository's upstream pin is still unverified.

| Candidate | Scientific feasibility | Confounds and requirements before implementation |
|---|---|---|
| Cylinder Re / viscosity | Potentially feasible between episodes on a common grid | Registered easy→medium changes Re and resolution; saved solver viscosity and force viscosity must agree. New Re requires explicitly authorized new initial states/reference statistics. Match grid, inlet, CFL and transient treatment; verify time/grid convergence. Within-episode viscosity mutation is not validated. |
| RBC Ra or Pr | Potentially feasible as controlled transport-coefficient changes | Ra changes both ν=√(Pr/Ra) and κ=1/√(RaPr); Pr changes their ratio. State which physical pathway is intended and hold the other dimensionless parameters fixed. Difficulty also changes CFL. Existing domain keys do not encode all geometry/numerical choices. Need native heat-flux consistency and thermal boundary-layer resolution checks. |
| Airfoil Re | Potentially feasible at fixed geometry/grid | Loaded ν, force normalization, reference Cl/Cd and initial-state distributions must be consistent. 3D hard refines the tail. Need near-wall resolution and force convergence; do not infer separation or transition solely from force spectra. |
| TCF Reτ / forcing | Not yet a clean prescribed one-parameter shift | Reτ maps to centerline Re, ν, wall velocity and time units; dynamic forcing depends on wall stress. Holding a registry argument fixed does not guarantee matching realized bulk flow or wall units. Requires profiles, wall stresses, transport/forcing audit and costly 3D validation. |
| Actuator gain | A wrapper can represent actuator effectiveness without solver edits | It changes control authority, not uncontrolled bulk-flow physics. Zero-action characterization cannot validate its response. Need separate bounded excitation and measured boundary flux/temperature response, preserving smoothing and action limits. No method chosen. |
| Inlet, geometry, blockage, wall/outlet conditions | Not currently supported as a clean nominal wrapper change | Source constants, stored boundary data, outlet speed, normalization and reference statistics are coupled. Would need an external supported construction/subclass pathway and explicitly new datasets; solver edits are out of scope. |
| Numerical dt/CFL/grid | Feasible numerical sensitivity studies, not physical shifts | Must be labeled discretization studies. They are needed to separate numerical artifacts from physical response and are not part of this nominal matrix. |

The nominal matrix can establish measurement availability, numerical failure rates, repeatability and initial-condition variability. It cannot establish causal shift sensitivity, bifurcation boundaries, chaos, turbulence, actuator dynamics, or robust-control performance. Registered variant comparisons are descriptive multi-factor comparisons unless their co-changes are controlled in a later design. Review the nominal evidence before deciding which candidate warrants a controlled experiment.
